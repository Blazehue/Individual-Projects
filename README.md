## 📋 Overview

This repository contains a collection of individual projects that demonstrate various programming skills and technologies. The projects include a portfolio website and a sales database management system.

## 📁 Project Structure

- **Portfolio/**: A personal portfolio website
- **Sales Database Management.py**: A Python script for sales database management

## 🎯 Projects

### 1. Portfolio Website
A personal portfolio website showcasing skills, projects, and experience.

### 2. Sales Database Management
A Python script for managing sales database operations.

## 🛠️ Technologies Used

- **Python**: For backend/database management
- **HTML/CSS**: For frontend web development
- **JavaScript**: For interactive web elements

## 🚀 Getting Started

1. **Clone the repository**:
   ```bash
   git clone https://github.com/Blazehue/Individual-Projects.git
   ```

2. **Navigate to the project directory**:
   ```bash
   cd Individual-Projects
   ```

3. **Run the Python script**:
   ```bash
   python "Sales Database Management.py"
   ```

4. **Open the portfolio website**:
   Navigate to the Portfolio directory and open the index.html file in your browser.
